## What to build

Implement `taskr dep-tree <id>` — renders an ASCII tree of a ticket's dependencies.

Default: first-degree only. `--full` expands recursively to leaf nodes.

## Acceptance criteria

- [x] `taskr dep-tree <id>` prints first-degree deps as ASCII tree
- [x] `--full` recursively expands all deps to leaves
- [x] Each node shows ticket ID and current status
- [x] Accepts partial IDs
- [x] Ticket with no deps prints just the root node
- [x] Works for tickets in both `.tickets/` and `.tickets/archive/`
