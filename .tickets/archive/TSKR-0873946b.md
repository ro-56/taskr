## What to build

Ship pre-built binaries via GitHub Releases and provide one-liner install scripts.

- **Release hosting**: GitHub Releases, triggered by pushing a semver tag
- **Build pipeline**: GoReleaser + GitHub Actions
- **Target platforms**: Linux amd64 + arm64, macOS amd64 + arm64, Windows amd64
- **Install scripts**: `install.sh` (Linux/macOS) and `install.ps1` (Windows)
- **Install location**: user-local — `~/.local/bin` (Linux/macOS), `%LOCALAPPDATA%\taskr\` (Windows)
- **Checksums**: scripts verify SHA256 before installing
- **Version selection**: installs latest by default; `TASKR_VERSION` env var overrides

## Acceptance criteria

- [x] `.goreleaser.yml` builds all 5 platform targets
- [x] GoReleaser injects version via ldflags
- [x] `.github/workflows/release.yml` triggers on `push: tags: ['v*']`
- [x] `install.sh` detects OS/arch, downloads, verifies SHA256, extracts, adds to PATH
- [x] `install.sh` respects `TASKR_VERSION` env var
- [x] `install.ps1` mirrors the above for Windows
- [x] README updated with one-liner install commands
